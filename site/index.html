You type fix the flaky token test into a plain terminal, forgetting you're not in Claude Code. else.sh catches the command not found, shows you the prompt, and on Enter starts your agent with it.

$ curl -fsSL https://cristi-boboc.github.io/else.sh/install.sh | sh
PS> irm https://cristi-boboc.github.io/else.sh/install.ps1 | iex
$ go install github.com/cristi-boboc/else.sh/cmd/else.sh@latest && else.sh install

Detects your OS and CPU, verifies the checksum, hooks the shell you ran it from and picks the first agent it finds as the default.

How it decides

else.sh sees lines your shell could not run, and asks one question: did you mean to talk to an agent? Questions get through even when their first word is a real command: a line starting with what, why, how or explain with three or more words, or any question ending in ?, is handed over when you press Enter.

You typeResultBecause

  • A line that starts with a real command runs it: make the tests pass runs make. Use else.sh ask make the tests pass for those.
  • Apostrophes work in question lines (what's in this repo). Elsewhere an apostrophe still opens a quote and the shell waits for more input.
  • Set ELSE_SH_DEBUG=1 to see why a line was or wasn't handed over.

Shells

Each shell already has a hook for unknown commands; else.sh uses it. If something was there before, such as Ubuntu's package suggestions, it still runs whenever else.sh passes on a line.

ShellHookWritten to
zshcommand_not_found_handler~/.zshrc
bash 4+command_not_found_handle~/.bashrc, or ~/.bash_profile on macOS
fishfish_command_not_found~/.config/fish/conf.d/else.sh.fish
PowerShell 7, Windows PowerShell 5.1CommandNotFoundAction$PROFILE.CurrentUserAllHosts
  • macOS ships bash 3.2, which has no hook. zsh is the default there; for bash, brew install bash.
  • cmd.exe has no unknown-command hook, so it isn't supported. Use PowerShell or Windows Terminal with pwsh.

Config

One TOML file at ~/.config/else.sh/config.toml (%APPDATA%\else.sh\config.toml on Windows). Add any agent that takes a prompt on its command line.

default_agent = "claude"
min_words     = 2      # shorter lines count as typos, unless they end with "?"
typo_guard    = true   # skip lines one edit away from a real command
confirm       = true   # Enter sends, e edits, Esc cancels; false sends at once

# change how a built-in agent starts
[agents.claude]
args = ["--model", "opus", "{prompt}"]

# or add your own
[agents.mine]
command = "my-agent"
args    = ["chat", "{prompt}"]
# everyday commands
else.sh agents          # what's installed, and the default
else.sh use gemini      # change the default
else.sh ask make it so  # skip the guessing
else.sh off             # pause it (ELSE_SH_DISABLE=1 for one terminal)
else.sh doctor          # what was detected
else.sh uninstall       # remove the hook
